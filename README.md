# Nils-Styles

Nils-Styles is a Minecraft mod that allows players to easily select and apply different texture packs directly from within the game. This mod provides a user-friendly interface to manage texture packs, making it easier to switch between different visual styles for items like swords, armor, and blocks. The mod supports installing texture packs from local files and applying them with a few simple steps.

## Install

1. **Download the Mod**: Obtain the Nils-Styles mod file from the GitHub repository or the EnderDevelopment marketplace.
2. **Install Fabric Loader**: Ensure you have Fabric Loader installed for Minecraft version 1.21.11.
3. **Place the Mod**: Move the downloaded mod file into the `mods` folder of your Minecraft directory.
4. **Launch Minecraft**: Start Minecraft using the Fabric profile to load the mod.

## Use

1. **Open the Menu**: Press the 'R' key to open the Nils-Styles menu.
2. **Install a Texture Pack**: Click on the "Install Texture Pack" button and select the texture pack file from your local directory.
3. **Select a Skin**: Click on the "Select Skin" button to choose a skin for items like swords or armor from the available texture packs.
4. **Apply the Skin**: Select the desired skin from the list and apply it to see the changes in-game.
